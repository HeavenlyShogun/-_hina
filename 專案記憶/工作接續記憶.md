## Phase 1–4 完成狀態

- **Phase 1 / 1.5：** MIDI 低階事件轉 Slim 與匯出往返保留原始 track index、program change、同 tick 順序及 FIFO 音符配對。Slim 軌道前五欄維持相容，新增 `sourceTrackIndex`、`programChanges`；音符保留 note-on/off 原始 order。`midi-file` 是正式 dependency。
- **Phase 2：** Firestore 使用 `ownerUid`、`isPublic`、`copiedCount`；非擁有者複製須原子建立唯一 ledger 並僅遞增一次。私人 Storage `score.json` 限擁有者讀取，寫入限 JSON 與 20 MiB。
- **Phase 3：** 播放控制器管理自己的 timer／RAF，Playback Request Sequence 防止非同步 resume 後過期播放或 Seek 重啟；音訊引擎安全釋放音符；譜面預覽隔離高頻 playhead 訂閱；新 MIDI 匯入使用 Slim，保留 V2/V3 相容讀取。
- **Phase 4：** GitHub Actions 設定 Node 22、Java 21、單元測試、Firestore/Storage Emulator rules 測試與 build。Playwright 報告與 Vite 日誌已移出 Git index 並加入 `.gitignore`。README 與主題記憶已同步。
