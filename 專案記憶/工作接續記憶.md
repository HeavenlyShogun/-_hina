## 本輪完成事項

- 建立 Runtime round-trip 對照 MIDI 輸出：npm run fixtures:midi:export，輸出在 tests/fixtures/midi/roundtrip/；DAW A/B SOP 在 fixtures README。
- round-trip 覆蓋 PPQ 96/480/960、tempo map、拍號、多軌/空軌、Channel 10、Program Change、1 tick、密集和弦及 velocity 邊界。
