## 目前有效狀態

- 穩定版本仍為 `1.1.0`。
- 使用者直接讀取入口為 JSON / Slim JSON；MIDI、MusicXML、MXL 先經轉檔區產生可載入 payload。
- Firebase 已支援一鍵生成分享連結：公開譜面寫入 `publicScores`，URL 使用 `?scoreId=` 載入。
- Firestore 初始化使用 persistent local cache，支援離線優先快取與恢復網路後同步。
- 編輯器已支援 3 秒 debounce 背景自動同步，狀態顯示為「雲端同步排程中 / 同步中 / 已同步」。
- `ScoreLibrary` 有「我的樂譜」與「玩家共享」分頁，公開譜面可載入或複製到自己的雲端曲庫。
- 預設 slim 譜面目前為 20 首，來源目錄是 `風物之琴譜/縮小版可匯入譜面/slim-json/`。
- `tada-koe-hitotsu-slim.json` 是目前保留的新增預設譜面。
- `guitar-loneliness-and-blue-planet-slim.json`、`seiza-ni-naretara-slim.json`、`zattou-bokura-no-machi-slim.json` 不作為目前預設 slim 譜面。
- 播放中會鎖定樂器切換，避免播放排程期間變更 tone 造成聲音狀態不一致。
- Rhythm 控制面板有獨立 Web Audio 節拍器，click 不走 `playbackController`，不改變譜面播放排程。
- 主 BPM 套用已用 `requestAnimationFrame` 節流，拖曳滑桿時避免同一 frame 內重複推送。
- 主要背景實際執行路徑為 `src/assets/galaxy-background.jpg`。
- `galaxy.png` 已納入 git 追蹤。
- `tone@15.1.22` 是 production build 需要的依賴。
- `Tone.Sampler` 載入有 timeout fallback，避免 sample CDN 或測試瀏覽器卡住播放 Promise。

## 維護規則

- 新增或修改功能時，同步更新對應主題檔的「作業位置」與「除錯入口」。
- 跨領域改動要同時更新多份記憶。例如：匯入 MIDI 後自動上傳雲端，需更新 `03` 與 `04`。
- 不把臨時 log、build 產物、preview port 或個人本機狀態寫成長期事實；只保留會影響後續判斷的驗證結論。
- 若發現亂碼、失效路徑、已移除 API，直接修正主題檔正文，不新增覆蓋補丁檔。
- `dist`、`dist-fb`、`dist-gh`、`.tmp`、`node_modules` 是產物或依賴，不作為原始碼修改來源。
