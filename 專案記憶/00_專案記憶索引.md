# Project Hina 專案記憶索引

最後更新：2026-05-29

本目錄用來記錄 Project Hina 的長期工程記憶、作業位置與除錯入口。更新功能時，先找到對應主題檔，再把實作檔案、資料流、限制與待修項目寫回該檔。

## 快速入口

- 樂器發聲、無聲、爆音、音色載入：先看 `06_樂器發聲與音訊引擎記憶.md`。
- 美術、版面、響應式、背景與按鈕狀態：先看 `07_美術與介面設計記憶.md`。
- 樂譜 schema、MIDI、MusicXML、Slim JSON、匯入匯出：先看 `03_譜面系統與轉換記憶.md`。
- Firebase Auth、Firestore 曲庫、批次上傳：先看 `04_Firebase與雲端曲庫記憶.md`。
- GitHub Pages、Firebase Hosting、base path 與部署：先看 `05_GitHub與部署記憶.md`。
- 專案根目錄、資料夾、腳本、建置輸出與日常驗證：先看 `08_基礎組成元素與作業位置.md`。

## 記憶拆分

- `01_目前系統總覽.md`
  - 專案技術棧、主要資料流、核心模組與目前風險。
- `02_頁面欄位與記憶更新邏輯.md`
  - App 各頁面、欄位、狀態來源與記憶更新規則。
- `03_譜面系統與轉換記憶.md`
  - 樂譜 schema、MIDI/MusicXML/Slim JSON 轉換、匯入匯出與 AI 輔助轉檔。
- `04_Firebase與雲端曲庫記憶.md`
  - Firebase 設定、Auth、Firestore、雲端曲庫與上傳限制。
- `05_GitHub與部署記憶.md`
  - GitHub remote、GitHub Pages、Firebase Hosting、build/deploy 指令。
- `06_樂器發聲與音訊引擎記憶.md`
  - 樂器清單、SoundFont/sample、Web Audio 合成、播放排程與音色除錯。
- `07_美術與介面設計記憶.md`
  - 視覺資產、版面、控制元件、互動狀態與 UI 品質規則。
- `08_基礎組成元素與作業位置.md`
  - 專案目錄、設定檔、腳本、資料資產、測試與日常維護入口。

## 維護規則

- 新增或修改功能時，同步更新對應主題檔的「作業位置」與「除錯入口」。
- 跨領域改動要同時更新多份記憶。例如：匯入 MIDI 後自動上傳雲端，需更新 `03` 與 `04`。
- 不把臨時 log、build 產物或個人本機狀態寫成長期事實。
- 若發現亂碼、失效路徑、已移除 API，優先修正記憶文件，避免後續依賴錯誤資訊。
