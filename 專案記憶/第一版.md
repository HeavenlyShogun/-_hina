# 第一版：Legacy 相容邏輯（Revised V1）

更新日期：2026-05-08

本檔定義 Project Hina 第一版鋼琴／風物之琴譜的相容邏輯。之後凡是提到「第一版」、「舊版模式」或 `legacy`，都以這份規則為準。

## 狀態

已存在，保留相容，但只作為舊譜匯入與回放相容層，不作為新功能的主要資料模型。

## 核心定位

第一版以鍵盤字母直接代表琴鍵，保留早期文字譜手感與排版習慣；實際節奏採絕對步進累加，而不是 slash cell 均分。

## 對應格式與參數

| 項目 | 定義 |
|---|---|
| storage format | `legacy-text@1` |
| text notation | `textNotation: "legacy"` |
| timing mode | `legacyTimingMode: "absolute"` |
| default resolution | `charResolution: 8` |

## 核心規則

- 節奏基準採字元單位制。每個有效字元單位固定消耗 1 個時間步進。
- 空白是時間推進器。遇到空白時，時間游標前進 1 個單位。
- 斜線 `/` 是拍子對齊器。它本身不固定耗時，只會把目前時間推進到下一個拍點邊界。
- 連彈 `AB` 依序觸發。`A` 與 `B` 各前進 1 格，總共消耗 2 格時間。
- 和弦 `(ABC)` 同步觸發。括號內音符同時發聲，整組完成後只前進 1 格時間。
- 休止 `0` 視為明確休止事件，仍保留給顯示與練習判定。
- 換行只影響排版，不影響時間軸。
- 音域鍵位沿用既有鍵位映射，大小寫正規化為相同鍵位。

## 使用原則

- 只有匯入舊譜、修復舊譜相容性、或需要保留早期鍵位手感時，才使用第一版。
- 新功能不應優先依附第一版格式。
- 第一版輸入進入播放器與顯示層前，仍應先轉成 canonical event。
- 任何 `legacy-beat` 或「斜線槽均分」解讀都不應再作為第一版的預設規則。
