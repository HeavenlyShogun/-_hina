# 第一版：舊版鍵位譜邏輯

更新日期：2026-05-08

本檔記錄 Project Hina 第一版鋼琴／風物之琴彈奏邏輯。說「第一版」、「1 版」或「舊版邏輯」時，指本檔定義。

## 狀態

已存在，保留相容。

## 核心定位

第一版以鍵盤字母直接代表琴鍵，靠 `/` slash cell 切節奏。它重視原本手感與文字排版中的時間感，主要用於匯入舊譜、保留早期風物之琴譜的相容性。

## 對應格式與參數

| 項目 | 定義 |
|---|---|
| storage format | `legacy-text@1` |
| text notation | `textNotation: "legacy-beat"` |
| timing mode | `legacyTimingMode: "beat"` |
| resolution control | `charResolution` |

## 規則

| 規則 | 記憶定義 |
|---|---|
| 節奏核心 | 每個 `/` 結束一個時間槽。時間槽長度由 `charResolution` 決定，預設可視為 16 分音符格線。 |
| 槽內分配 | 槽內的音符、和弦、休止與空白都會參與時間分配。空白不能被任意 trim，因為它可能代表等待。 |
| 單音 | 例如 `A`、`Q`、`Z`，直接對應鍵盤琴鍵。 |
| 快速連彈 | 例如 `AB`，表示同一 `/` 時間槽內連續觸發 A、B，依槽內事件數平均切 onset。 |
| 和弦 / 撥奏 | 例如 `(ABC)`，括號內視為同一事件，播放時可保留微小撥奏延遲。 |
| 休止 | `0` 是明確休止事件，輸出時仍保留給顯示與練習判定。 |
| 音域鍵位 | `A-J` 中音排、`Q-U` 高音排、`Z-M` 低音排，大小寫正規化為同一鍵位。 |
| 風險 | 適合保留舊譜，但不適合作為長期主資料模型；播放、顯示、轉調與驗證都需要額外相容層。 |

## 使用原則

- 只有匯入舊譜、修復舊譜相容性、或需要保留早期鍵位手感時，才回到第一版。
- 新功能不應優先接到第一版。
- 第一版輸入若要進入播放器與顯示層，仍應先轉成 canonical event。
