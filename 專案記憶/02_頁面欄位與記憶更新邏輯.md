# 頁面欄位與記憶更新邏輯

最後更新：2026-05-15

## 維護原則

- 每次改某個頁面區塊時，要同步更新本檔對應章節。
- 若改動超出單一區塊，還要同步更新：
  - `01_目前系統總覽.md`
  - `03_譜面系統與轉換記憶.md`
  - `04_Firebase與雲端曲庫記憶.md`
  - `05_GitHub與部署記憶.md`

## 主畫面 `main-screen`

- 主要元件：`src/pages/PianoRoom.jsx`
- 主要欄位：
  - featured scores
  - score groups
  - busy badge
  - jump to section
- 若修改：
  - 曲目來源或曲目分類，更新 `01_目前系統總覽.md`
  - 首頁版位或導覽順序，更新本檔與 `01_目前系統總覽.md`

## 鍵盤 `lyre-keyboard`

- 主要狀態：
  - `activeKeys`
  - `keyPulseTokens`
  - `noteTrail`
  - `playHotkey`
  - 升降記號切換 `accidentals`
- 若修改：
  - 鍵位映射或可視化效果，更新本檔
  - 若影響實際演奏音高或正規化結果，更新 `03_譜面系統與轉換記憶.md`

## 節奏與調性 `rhythm-controls`

- 主要欄位：
  - `bpm`
  - `timeSigNum`
  - `timeSigDen`
  - `charResolution`
  - `tone`
  - `reverb`
  - `globalKeyOffset`
  - `scaleMode`
  - `accidentals`
- 實際來源：
  - `useScoreState`
  - `AudioConfigContext`
- 若修改：
  - 欄位名稱、預設值、同步路徑，更新本檔與 `03_譜面系統與轉換記憶.md`

## 演奏預覽 `playback-preview`

- 主要元件：`src/components/PerformanceWorkspace.jsx`
- 主要欄位：
  - 播放時間軸
  - section / token preview
  - seek / scrub
- 若修改：
  - 預覽資訊粒度、時間軸呈現、seek 行為，更新本檔
  - 若改動依賴的正規化結構，更新 `03_譜面系統與轉換記憶.md`

## 譜面編輯 `editor`

- 主要元件：
  - `src/components/SheetDisplay.jsx`
  - `src/components/ScoreEditor.jsx`
- 主要欄位：
  - `scoreTitle`
  - 匯入本機檔案
  - 下載 JSON
  - 下載 MIDI
  - 下載原始譜面
  - 存入雲端
  - 重設
  - JSON 摘要卡
  - 文字編輯區
- 記憶更新邏輯：
  - 若匯出格式有變，更新 `03_譜面系統與轉換記憶.md`
  - 若雲端存檔按鈕或狀態有變，更新 `04_Firebase與雲端曲庫記憶.md`
  - 若 editor UI 摘要卡或讀寫規則有變，更新本檔與 `01_目前系統總覽.md`

## 譜面轉換 `converter`

- 主要元件：`src/components/ScoreConverter.jsx`
- 主要欄位：
  - 選擇多個 MIDI
  - 選擇多個 MusicXML
  - 批次上傳
  - 清除本批
  - 拖放 MusicXML 區
  - 待上傳清單
  - 覆蓋到譜面編輯
  - 接到後面
  - AI 輔助轉換
  - `Source Draft`
- 記憶更新邏輯：
  - 若更動匯入格式、佇列行為、覆蓋/接續規則，更新 `03_譜面系統與轉換記憶.md`
  - 若更動批次上傳雲端流程，更新 `04_Firebase與雲端曲庫記憶.md`
  - 若更動 AI 提示詞 schema 或用途，更新 `03_譜面系統與轉換記憶.md`
- MIDI 匯入 UI 應明確表示目前採用「MIDI 播放器式 preset」：
  - 顯示 BPM、拍號、PPQ、tempo map、track、channel、instrument、program。
  - 載入後優先使用檔案內 `transport` / `playback`，再提供本機控制面板微調。
  - 若改動這套同步規則，必須同步更新 `03_譜面系統與轉換記憶.md`。

## 雲端曲庫 `cloud-library`

- 主要元件：`src/components/ScoreLibrary.jsx`
- 主要欄位：
  - 連接 Firebase
  - Save
  - 雲端摘要列表
  - 載入、刪除、清空
- 記憶更新邏輯：
  - 若更動登入、列表摘要、讀取、上傳、刪除、清空，更新 `04_Firebase與雲端曲庫記憶.md`
  - 若更動部署或環境需求，更新 `05_GitHub與部署記憶.md`

## 導覽側欄 `Workspace`

- 定義位置：`src/App.jsx`
- 若工作區順序、id、caption、跳轉邏輯改動：
  - 必須同步更新本檔
  - 必須同步更新 `01_目前系統總覽.md`
  - 若首頁也有對應快捷導覽，需一起檢查
