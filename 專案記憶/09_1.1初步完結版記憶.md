
# universe rhythm recorder 1.1 初步完結版記憶

最後更新：2026-06-05

## 版本狀態

- 專案版本：`1.1.0`。
- 版本來源：`package.json`，由 `vite.config.js` 注入 `__APP_VERSION__`，畫面右下角顯示 `v1.1.0`。
- 目前穩定目標：單頁音樂工作台，整合鍵盤演奏、譜面編輯、MIDI / MusicXML / MXL 轉換、Firebase 曲庫與 GitHub Pages / Firebase Hosting 部署。
- 本檔記錄 2026-05-29 的 1.1 初步完結版歷史基準；預設曲庫、部署驗證、背景資產等最新狀態以 `03`、`05`、`07`、`10` 為準。

## 1.1 完成功能

- 背景區塊位於頁面下方，作為欣賞星空背景與專案背景說明的低干擾空間。
- 背景介紹區提供「淡化介紹 / 顯示介紹」按鈕，可手動隱藏文字卡片，只保留背景欣賞。
- 鍵盤播放區已提供「播放」、「暫停 / 繼續」、「從頭」三種控制，時間軸仍可拖曳定位。
- 譜面編輯區已精簡為 JSON / MIDI 流程摘要：目前只讀取 JSON/Slim JSON；MIDI、MusicXML、MXL 先經轉換區產出 JSON。
- 調性設定改為現實樂理可對應的「大調（Ionian）」與「自然小調（Aeolian）」，移除未實作的自訂音階選項。
- 節奏與調性選單改用深色底與明確文字色，避免展開選單空白或難讀。

## 底層樂理系統

- 可讀取格式：
  - 直接讀取 JSON V2 與 Slim JSON 3.2。
  - MIDI、MusicXML、MXL 經轉換區輸出 JSON 後載入。
  - 舊版鍵盤文字譜、數字譜、keshifu 與 numbered-grid 不再作為使用者讀取入口。
- 大小調：
  - 大調：`[0, 2, 4, 5, 7, 9, 11]`。
  - 自然小調：`[0, 2, 3, 5, 7, 8, 10]`。
  - 主音由 `globalKeyOffset` 決定；MIDI / MusicXML 來源優先保留原始 MIDI 音高。
- MIDI / MusicXML / MXL：
  - 轉為 JSON 或 Slim JSON 後播放。
  - 大型 JSON 在編輯區以摘要顯示並保持唯讀，避免文字區載入過重。

## 後續維護規則

- 不再新增「自訂音階」選項，除非同時實作可配置音階 interval。
- 修改譜面格式教學時，必須以 `src/utils/score.js`、`src/utils/midiToV2.js`、`src/utils/musicXmlToSlim.js` 的實際解析邏輯為準。
- 部署前固定跑 `npm.cmd run build:firebase` 與 `npm.cmd run build:pages`。
- 清理舊檔時優先清理 build output、暫存與 Python cache，不刪原始曲庫、腳本、專案記憶主題檔。
