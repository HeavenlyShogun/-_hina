轉檔產線使用方式

日後只要將 .mid 放入 風物之琴譜/縮小版可匯入譜面/midi/，並執行：

cmd /c npm run scores:slim:library


腳本會自動完成：MIDI 轉 Slim JSON -> 產出 Manifest -> 更新索引。
若需強制覆寫既有 JSON，可附加參數：cmd /c npm run scores:slim:library -- --force
