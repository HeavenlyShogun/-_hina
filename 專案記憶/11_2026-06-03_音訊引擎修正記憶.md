# 2026-06-03 音訊引擎修正記憶

## 修正目標

- 解決平台鋼琴與其他樂器在部分譜面中無法正常切換的問題。
- 解決部分譜面短時間大量音符造成爆音的問題。
- 原聲樂器使用 `Tone.Sampler` 載入 `.wav` sample。
- 電子合成主音使用 `Tone.PolySynth` 由數學波形生成。

## 實作內容

- `src/constants/music.js`
  - `normalizeToneSelection()` 改為永遠回傳單一 tone id。
  - 舊譜面或舊 UI 狀態若帶入 tone array，只取第一個合法 tone，避免多音色疊加。

- `src/components/InstrumentSelector.jsx`
  - 樂器 UI 改為單選。
  - 移除未使用且亂碼的 legacy instrument dead code。

- `src/constants/instruments.js`
  - 重建樂器定義，保留既有 id。
  - 補齊可選原聲樂器：Piano、Guitar、Harp、Flute、Drums。
  - 保留 Tongue Drum 與電子主音類。

- `src/services/audioEngine.js`
  - 原聲音色走 `Tone.Sampler`。
  - Piano / Guitar / Harp / Flute 使用 `tonejs-instruments` 的 `.wav` sample path：
    - `https://nbrosowsky.github.io/tonejs-instruments/samples/piano/`
    - `https://nbrosowsky.github.io/tonejs-instruments/samples/guitar-acoustic/`
    - `https://nbrosowsky.github.io/tonejs-instruments/samples/harp/`
    - `https://nbrosowsky.github.io/tonejs-instruments/samples/flute/`
  - Drums 使用 Oramics Pearl acoustic drums `.wav`：
    - `https://oramics.github.io/sampled/DRUMS/pearl-master-studio/samples/`
  - `tonejs-instruments` 來源：
    - https://github.com/nbrosowsky/tonejs-instruments
  - 修正 direct sample fallback 的 URL 組合，讓 Web Audio fallback sampler 也能用 `baseUrl + wav filename`。
  - 電子合成主音明確使用 `engine: 'polysynth'`：
    - `tongue-drum-electronic`
    - `retro-saw-synth`
    - `cozy-triangle-lead`
  - 密集音符增益底限調整為 `DENSE_NOTE_GAIN_FLOOR = 0.16`。

- `src/services/playbackController.js`
  - `normalizeEvents()` 計算同一 tick 的 `simultaneousNotes`。
  - 排程每顆音時把 `simultaneousNotes` 傳入 `audioEngine.scheduleNote()`。
  - `audioEngine.resolveRenderConfig()` 以 `1 / sqrt(simultaneousNotes)` 產生 `denseGainScale`，降低密集和弦、多音軌短時間齊發的爆音風險。
