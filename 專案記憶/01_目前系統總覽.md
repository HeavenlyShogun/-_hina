# Project Hina 目前系統總覽

最後更新：2026-05-15

## 技術現況

- 前端：React + Vite。
- 樣式：Tailwind CSS + Lucide React。
- 音訊：Tone.js / `@tonejs/midi`，播放控制集中在 `src/services/playbackController.js` 與 `src/hooks/useScorePlayback.js`。
- 雲端：Firebase Auth + Firestore + Firebase Hosting。
- 狀態主軸：
  - 譜面主狀態：`src/hooks/useScoreState.js`
  - 音色設定：`src/contexts/AudioConfigContext.jsx`
  - 播放狀態：`src/contexts/PlaybackContext.jsx`

## 目前譜面系統

- 編輯器主格式是 JSON `version: "2.0"`。
- 主要結構：
  - `meta`
  - `transport`
  - `playback`
  - `source`
  - `tracks[].events[]`
- 播放與預覽前，所有來源都會經過 `normalizeScoreSource()` 正規化。
- 支援的來源：
  - 文字譜
  - JSON 譜
  - MIDI
  - MusicXML
  - Slim Score `version: "3.2-ultra-slim"`

## 頁面工作區順序

`src/App.jsx` 的工作區順序目前是：

1. 主畫面
2. 鍵盤
3. 節奏與調性調整
4. 演奏預覽
5. 譜面編輯
6. 譜面轉換
7. 雲端曲庫

側欄 `Workspace` 導覽順序必須和這個順序一致。

## 主要頁面區塊

- `PianoRoom`
  - 主畫面、選曲、鍵盤入口、快速跳區塊。
- `PerformanceWorkspace`
  - 播放預覽、時間軸、分段區塊導覽。
- `SheetDisplay` / `ScoreEditor`
  - 譜面編輯、JSON 摘要、匯入、下載、存檔、重設。
- `ScoreConverter`
  - MIDI / MusicXML 批次讀取、待上傳清單、覆蓋或接到後面、AI 輔助轉換。
- `ScoreLibrary`
  - Firebase 曲庫列表、讀取、刪除、清空。

## 目前轉換器狀態

- 不再以 `Current Payload` 當主要畫面。
- 主畫面是：
  - 批次匯入按鈕
  - 待上傳清單
  - AI 輔助轉換
- 手動貼譜 / 草稿貼上區已收進 AI 區的 `Source Draft`。
- 轉換結果載入到編輯器有兩種動作：
  - 覆蓋到譜面編輯
  - 接到後面

## 譜面編輯區目前狀態

- 支援下載：
  - JSON
  - MIDI
  - 原始譜面
- JSON 譜面會顯示摘要卡：
  - title
  - format
  - BPM
  - time signature
  - tracks 與 event 數

## 雲端曲庫定位

- Firebase 曲庫現在是使用者同步與摘要管理系統，不是大型譜面 CDN。
- 大型譜面仍應優先轉成 Slim JSON 或採用靜態檔案方式，而不是直接把肥大 JSON 長期塞進 Firestore。
