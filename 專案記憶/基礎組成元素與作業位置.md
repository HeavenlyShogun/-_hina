基礎組成元素與作業位置

最後更新：2026-09-19

本檔記錄專案的基礎目錄、設定檔、腳本與日常維護入口。

根目錄與原始碼目錄

package.json：npm scripts、dependencies。

vite.config.js：Vite build、base path 設定。

src/components, src/pages, src/hooks, src/contexts, src/services, src/utils：專案核心邏輯。

src/data/importableScoreFiles.js：已重構為非同步載入，透過呼叫 scoreLibraryService 獲取曲目清單。

資料與工具

風物之琴譜/縮小版可匯入譜面/slim-json/：47 首輕量化 JSON 譜面來源。

風物之琴譜/縮小版可匯入譜面/midi/：對應的 MIDI 原始檔案。

scripts/batch-slim-midi-library.mjs：MIDI 批次轉 slim JSON 腳本。

scripts/generate-score-manifest.mjs：產生 public/score-library-manifest.json 全域索引。

scripts/slim-json-to-midi.mjs：反轉錄工具，可將 slim JSON 轉回 MIDI 以補齊缺失原始檔。

建置輸出

dist：一般 Vite build。

dist-fb：Firebase Hosting build。

dist-gh：GitHub Pages build。

public/score-library-manifest.json：前端非同步載入的曲庫清單索引（由腳本動態產出，請勿手動修改）。

可用驗證指令

Firebase build：npm.cmd run build:firebase

GitHub Pages build：npm.cmd run build:pages

曲庫轉檔產線：npm.cmd run scores:slim:library (自動包含產生 manifest)

MIDI 反轉錄修復：npm.cmd run scores:midi:reverse

本機新增 MIDI 串接入預設選單流程

把新 MIDI 放到 風物之琴譜/縮小版可匯入譜面/midi/。

執行指令：cmd /c npm run scores:slim:library。
(此指令會自動將 MIDI 轉為 slim JSON，並更新 public/score-library-manifest.json 索引)。

前端重新整理後，首頁清單即會透過 loadLibraryManifest() 自動抓取並顯示新曲目。

執行 npm.cmd run build:firebase 與 npm.cmd run build:pages 驗證。

已知維護重點

任何跨 Firebase/GitHub 的 build 改動，都要同時驗證兩種 base path。

舊版 Vite 的 surges-slim.json 重複載入與 >500kB JSON chunk 問題已於 2026-09-19 的雲端架構重構中徹底解決；目前全數改為非同步 Manifest 載入。

若發生 MIDI 原始檔遺失，可使用 npm.cmd run scores:midi:reverse -- --scan-missing 批次補齊。
