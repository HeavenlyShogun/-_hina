# 2026-06-05 節拍器與預設譜面修正記憶

最後更新：2026-06-05

本檔為 2026-06-05 之後的最新覆蓋記憶；若舊記憶提到預設譜面 21 首，或仍列出 Guitar, Loneliness and Blue Planet / 星座になれたら 為預設譜面，皆以本檔為準。

## 功能狀態

- `src/components/ControlPanel.jsx` 的 Rhythm 面板已加入可開關節拍器。
- 節拍器使用獨立 Web Audio click，不依賴譜面播放排程，避免影響 `playbackController` 的 tick-based transport。
- 節拍器速率可用滑桿與數字輸入調整，範圍為 30.0 到 240.0 BPM。
- 節拍器依目前拍號分子做重音，第一拍為較高頻 click。
- 原本的 BPM、拍號、Beat Grid、音量、殘響、主音與大小調控制仍保留。

## 預設譜面狀態

- 預設 slim 譜面路徑仍為 `風物之琴譜/縮小版可匯入譜面/slim-json/`。
- 預設 MIDI 原始檔路徑仍為 `風物之琴譜/縮小版可匯入譜面/midi/`。
- 目前預設 slim 譜面總數固定為 20 首。
- 新增並保留的預設譜面：`tada-koe-hitotsu-slim.json`，來源 MIDI 為 `ただ声一つ.mid`。
- 已從預設譜面移除：`guitar-loneliness-and-blue-planet-slim.json`、`seiza-ni-naretara-slim.json`。
- 為維持 20 首，也不保留 `zattou-bokura-no-machi-slim.json` 作為預設 slim 譜面。
- `Guitar, Loneliness and Blue Planet.mid` 與 `星座になれたら.mid` 已依需求自預設 MIDI 目錄移除。

## 驗證紀錄

- `npm install` 已補回本機缺少的 `tone@15.1.22`，正式建置需要此依賴。
- `npm run build` 已通過，輸出目錄為 `dist-fb`。
- 本機 preview server 已以 `dist-fb` 啟動於 `http://127.0.0.1:4173/`。
- HTTP 載入檢查回應 `200`，首頁 HTML 可正常取得。
- 本環境沒有 Playwright / Puppeteer，因此未做完整瀏覽器互動自動化量測；若需逐幀 FPS 或音訊互動測試，需另裝瀏覽器自動化工具或人工開頁確認。

## 後續維護規則

- 新增 MIDI 若要變成預設譜面，先放入 `風物之琴譜/縮小版可匯入譜面/midi/`，再用 `scripts/slim-midi-score.mjs` 輸出到 `slim-json/`。
- 若預設譜面數量有上限，新增一首時必須同步確認是否要移除或排除其他 slim JSON。
- `src/data/importableScoreFiles.js` 的 `IMPORTABLE_SCORE_ORDER` 只放要明確排序的預設譜面；實際可載入檔案仍由 Vite 的 `import.meta.glob` 掃描 `slim-json/`。
