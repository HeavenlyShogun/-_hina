# universe rhythm recorder 外接演奏控制器計畫

最後更新：2026-09-16  
狀態：提案；尚未選定 MCU、按鍵矩陣、接線與韌體。

## 目標與第一代範圍

製作一個可直接演奏網站琴鍵的外接控制器。第一代只負責「人按下／放開哪個音」；網站仍負責音色、音量、移調、譜面判定、播放與雲端資料，控制器不保存曲庫或 Firebase 資訊。

建議裝置名稱為 `Hina Lyre Controller`，裝置 ID 為 `hina-lyre-v1`，第一版硬體修訂為 `HW-REV-A`。

## 建議連線方式

優先採用 **USB class-compliant MIDI**：電腦不必安裝驅動，適合低延遲演奏，也可被其他音樂軟體辨識。瀏覽器端以 Web MIDI API 接收，使用者需在瀏覽器授權。

- 第一代必須：Note On、Note Off、velocity、裝置名稱／識別。
- 第一代可選：一個控制按鈕送 MIDI CC，作為播放／暫停。
- 不採用自訂 Serial 當正式協定；若原型暫時使用 Serial，必須由韌體轉成下列事件契約後才可納入正式版本。
- BLE MIDI 保留給第二階段。它會增加配對、斷線重連與平台相容測試，不應在第一代與 USB 併行開發。

## 硬體對軟體的介接契約

| 項目 | 第一代規格 |
| --- | --- |
| 傳輸 | USB MIDI class-compliant |
| 輸入音域 | 下表定義的 21 個自然音（C3–B5，MIDI 48–83）；其他 MIDI 音先忽略 |
| 按下 | `Note On`，channel 1，velocity 1–127 |
| 放開 | `Note Off`，或 `Note On velocity 0` |
| 同時按鍵 | 至少 5 鍵，須各自送出正確的按下與放開 |
| 去彈跳 | 韌體處理；不得因單次按壓送出重複 Note On |
| 延遲目標 | 實體按鍵到瀏覽器事件中位數小於 15 ms；量測方法記錄在本目錄 |
| 斷線處理 | USB 拔除時不應留下卡住的按鍵；軟體需釋放該裝置所有 active notes |

## 對既有軟體的影響

目前專案只監聽 `window` 的電腦 `keydown` / `keyup`（`src/hooks/useKeyboardHandler.js`、`src/hooks/useKeyboardMatcher.js`），沒有 Web MIDI 或其他外接裝置接收層。因此硬體接入前，需要在軟體端新增以下工作：

1. 建立 `useMidiInput` 或等價 adapter，將 MIDI Note On／Off 正規化為目前的網站琴鍵 ID。
2. 讓電腦鍵盤與外接 MIDI 共用同一個 `onKeyActivate` / `onKeyDeactivate` 路徑，避免判定、亮鍵、音訊播放各做一套。
3. 加入裝置選擇、授權狀態、連線／斷線提示與「全部放鍵」保護。
4. 將上述 21 個 MIDI note 的硬體 mapping 集中於一個軟體設定，不散落在 UI component；未來硬體修訂改音域時只改 mapping 與文件。
5. 新增自動化測試：Note On、velocity 0、Note Off、複音、拔除裝置、電腦鍵盤與 MIDI 同時輸入。

在上述軟體功能完成前，硬體可先用任何標準 MIDI monitor 驗證訊息，不能宣稱已與網站整合。

## 製作與驗證順序

1. 選定 MCU／開發板，確認原生 USB MIDI 支援與供電需求。
2. 決定 21 鍵排列、開關型號、二極體與矩陣掃描方式，建立 BOM 與接線圖。
3. 寫最小韌體：掃描、去彈跳、USB MIDI Note On／Off、開機裝置名稱。
4. 使用 MIDI monitor 驗證每一鍵、velocity、複音與長按放鍵。
5. 完成網站 Web MIDI adapter 後，量測實機延遲、斷線與重連、不同瀏覽器。
6. 最後才設計外殼、燈光與進階控制（旋鈕、踏板、BLE）。

## 主板本機音色與歌曲自動播放（韌體已撰寫、待實測）

最後更新：2026-09-23
狀態：規格已提供；`hina_lyre_main.ino` 已撰寫，尚未在實體板上編譯或測試。

目標是讓主板本機具備三排（低、中、高音域）琴鍵音色，並從 SD 卡載入歌曲資料後自動播放歌曲一次。此方向與原先 USB MIDI 網站控制器不同，韌體依 2026-09-23 提供的 ESP32 30-pin ESP-WROOM-32、VS1053B、共用 SPI MicroSD 及 4x6 矩陣規格撰寫。

網站的 21 鍵自然音對應 MIDI 48–83（非連續）。韌體於 VS1053B 載入 VLSI 官方 RT-MIDI 1.2 patch，以 MIDI Channel 0、Program 0 播放。新增檔案 `hina_lyre_main.ino` 內含 patch table，不依賴外部歌曲資料或 patch header；原先建立的空白 `arduino程式碼` 占位檔保留不動。

韌體實作與接線注意事項：

1. 本韌體依 ESP32 30-pin ESP-WROOM-32 撰寫；不同板型請先確認 GPIO 13/14/25/26/27/32/33/34/35/36 均有引出。
2. VS1053B 以 SPI 輸出音訊；依模組版本接妥耳機輸出或功率擴大器／喇叭，確認供電與邏輯電壓。
3. 歌曲以 MicroSD 根目錄 `/song.txt` 載入，每行 `MIDI音高,發聲毫秒,間隔毫秒`；範例在 `.ino` 檔案開頭。
4. 播放鍵開始播放一次，暫停鍵停止並送出 CC 123；歌曲結束後停止等待。
5. 目前使用單一 Acoustic Grand Piano 音色跨 21 音；矩陣未使用位置保留一格。GPIO34/35/36 需外接 10 kΩ 上拉；每顆按鍵建議串接矩陣隔離二極體。

程式尚未實機驗證；後續需依實際模組腳位、按鍵二極體方向與音訊放大器完成接線確認，再用 Arduino ESP32 core 編譯並實測 MIDI 音高、延遲、SD 播放、暫停與中斷清音。不要將撰寫完成視為硬體驗證完成。
