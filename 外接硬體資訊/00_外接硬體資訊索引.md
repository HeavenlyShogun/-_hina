# universe rhythm recorder 外接硬體資訊索引

最後更新：2026-09-23

本目錄只保存實體裝置的製作與驗證資訊：零件、接線、韌體、外殼、電源、裝置識別、實機測試，以及硬體對軟體送出的介接契約。

它與 `專案記憶/` 是兩套獨立記憶：

- `專案記憶/`：React 網站、樂譜、播放、雲端、部署與軟體程式碼。
- `外接硬體資訊/`：可製作的控制器、韌體與實體連線資訊；不得複製軟體系統總覽或部署細節。
- 兩者唯一共用的內容是「介接契約」。契約的硬體端定義放本目錄；軟體端實作位置只在 `專案記憶/` 記錄。

## 文件與命名規則

- `00_`：索引與跨文件規則。
- `01_` 至 `09_`：可執行的硬體計畫，例如 BOM、接線、韌體、外殼、測試紀錄。
- 檔名使用 `NN_主題.md`；實體原理圖、PCB、韌體專案放入以相同 `NN_` 開頭的子資料夾。
- 裝置 ID 使用小寫 kebab-case，例如 `hina-lyre-v1`；韌體版本使用 `vMAJOR.MINOR.PATCH`。
- 硬體修訂使用 `HW-REV-A`、`HW-REV-B`；不要用「最新」當作唯一識別。
- 尚未驗證的內容標示為「提案」，量測過的結果要寫日期、裝置 ID、韌體版本與結果。

- `hina_lyre_main.ino`：ESP32 30-pin、VS1053B RT-MIDI、MicroSD CSV 歌曲播放器與 4x6 鍵盤韌體；尚未實機編譯／測試。

## 作業分流

| 作業 | 儲存位置 | 何時同步另一側 |
| --- | --- | --- |
| 元件選型、接線、腳位、供電、韌體、外殼、實機延遲 | `外接硬體資訊/` | 改變 USB/BLE 傳輸格式、按鍵數或事件語意時 |
| Web MIDI 接收、裝置選擇 UI、鍵位映射、音訊與測試 | `專案記憶/` 與 `src/` | 改變硬體要求的事件欄位或支援範圍時 |
| 曲庫、Firebase、部署與網站品牌 | `專案記憶/` 與專案根目錄 | 通常不需同步硬體端 |

## 下次新增硬體資料時

1. 先在本目錄新增對應編號文件，填入裝置 ID、硬體修訂與狀態。
2. 若改變介接契約，同步更新 `硬體計畫資訊.md`，並在 `專案記憶/01_目前系統總覽.md` 留下軟體待辦或實作結果。
3. 不把 API key、Firebase 設定或個人裝置序號寫入硬體文件。
